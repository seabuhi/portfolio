# Project Images

Place your project screenshots/images in this folder.

## Naming Convention

Images should match the `image` field in `/data/projects.ts`:

- `savelya.png` - Savelya marketplace project
- `fitness.png` - Fitness tracker app
- `taskmanager.png` - Task management system
- `weather.png` - Weather dashboard
- `blog.png` - Blog CMS
- `chat.png` - Chat application

## Recommended Specs

- **Format**: PNG or JPG
- **Dimensions**: 1200x630px (or 16:9 aspect ratio)
- **Size**: < 500KB for optimal performance
- **Quality**: High-quality screenshots or mockups

## Fallback

If an image is missing, the ProjectCard will show a graceful glass placeholder with an icon.
